# ADR-001: Сховище даних — SQLite

## Контекст
Потрібне надійне збереження бронювань між перезапусками, без додаткової інфраструктури.

## Альтернативи
1. SQLite (файл).
2. PostgreSQL.
3. Зберігання в пам'яті.

## Рішення
SQLite через SQLAlchemy і Alembic.

## Переваги
Нуль зовнішніх залежностей, відтворюваний запуск, транзакції `BEGIN IMMEDIATE`.

## Недоліки
Один писач одночасно, немає горизонтального масштабування.

## Тригер перегляду
Понад кілька десятків одночасних записів або потреба в кількох інстансах.
