# Використані допоміжні засоби

Проєкт виконано з використанням генеративного асистента Claude Code (Anthropic) як автоматизованого виконавця:
він підготував код, тести, документацію та тексти PR/рев'ю, а заплановані дії (коміти, PR, рев'ю, оновлення Jira
і Confluence) виконувались автоматично за чергою кроків від імені учасників за їхньою згодою.
Кожен учасник відповідає за подані від його імені рішення й пояснює їх на захисті.
