# Правила злиття в main

Гілка `main` захищена на GitHub: злиття лише через pull request, потрібне щонайменше одне схвалення
рецензента й успішна перевірка CI `verify`. Автор не схвалює власний PR.
Робочий цикл: задача Jira → коротка гілка з ключем задачі → PR → рев'ю → CI → злиття → посилання в задачі.
