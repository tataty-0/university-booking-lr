## Процес
- Канбан: To Do → In Progress → Review → Done. Заблоковані задачі позначаються міткою `blocked`. Канбан обрано, бо обсяг невеликий, а залежності послідовні.
- Усі зміни через PR з однією рев'ю-перевіркою від іншого учасника та зеленим CI.
- Гілки: `feature/BOOK-<номер>-<опис>`, коміти за Conventional Commits.
- Рішення приймаються консенсусом; за розбіжності вирішує технічний лідер.
- Блокер понад пів дня — пишемо в команду та Jira, інший учасник допомагає.
- Знання передаються через код-рев'ю та Confluence.

## Definition of Done
1. Код змерджено через PR із зеленим CI.
2. Є автоматичні тести для нової поведінки.
3. Рев'ю виконане, блокуючі зауваження усунуто.
4. Jira-задачу оновлено з посиланням на PR.
5. Документацію в Confluence оновлено.
